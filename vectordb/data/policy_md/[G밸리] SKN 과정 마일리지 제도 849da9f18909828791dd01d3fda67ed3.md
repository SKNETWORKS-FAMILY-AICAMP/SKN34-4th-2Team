## 📅 단계별 미션 세부 내용

### 진행 시기 : 개강 전

- **예수학제 참여**
    - 디스코드 채널(예비수강생-공부인증) 인증 횟수에 따라 차등 지급
    - 3회 → 10,000원, 5회 → 30,000원, 10회 이상 → **50,000원(최대 금액)**
- **프리코스 퀴즈 제출**
    - 퀴즈 점수 60점 이상, 퀴즈 제출 횟수에 따라 차등 지급
    - 1회 → 10,000원, 3회 → 30,000원, 5회 → **50,000원(최대 금액)**
    

### 진행 시기 : 1~5 단위기간

- **블로그 작성**
    - 1~5단위기간 내 모든 주차 연속 작성 시, 단위기간별 2만원 지급
    - 5개월 연속 작성 시 마일리지 **100,000원(최대 금액)**
    

### 진행 시기 : 1~2 단위기간

- **스터디 인증**
    - 팀 스터디만 인정(개인 스터디 : 인정 X)
    - 인증 방식 : 학습 내용 캡처가 아닌, 오프라인 스터디 사진 촬영 후 주 1회 이상 참여 인증
        - 같은 스터디 팀원이더라도 인증은 개별 진행 필요
        - 사진의 경우, 학습한 날짜가 확인될 수 있도록 타임스탬프 어플 / 휴대폰 잠금화면 / 서버 시간 등 필수!
    - 학습 인정 내용 : 수업 예복습, 코딩테스트, 자격증, 사이드 프로젝트, 공모전 등 과정과 관련된 내용
    - 1단위기간부터 2단위기간까지 주 1회 이상 인증 시, 마일리지 **50,000원**
    

### 진행 시기 : 1~4 단위기간 내 상시

- **코딩 테스트**
    - PCCE 합격 후 레벨 취득 시, 마일리지 25,000원 지급
    - PCCP, PCSQL 합격 후 레벨 취득 시, 마일리지 **50,000원(최대 금액)**
    - PCCP, PCSQL 합격하여 50,000원 지급받은 사람은 PCCE 합격해도 추가 지급 없음
    
    ## 코딩테스트 마일리지 조건
    
    | 시나리오 | PCCE | PCCP/PCSQL | 지급 포인트 |
    | --- | --- | --- | --- |
    | 1 | 제출+매니저 승인 | 미제출 | **25,000** |
    | 2 | 제출+매니저 승인 | 제출+매니저 승인 | **50,000** (25K + 25K) |
    | 3 | 미제출 | PCCP 제출+매니저 승인 | **50,000** |
    | 4 | 미제출 | PCSQL 제출+매니저 승인 | **50,000** |

### 진행 시기 : 3, 4,  5 단위기간

- **출석률 100%**
    - 지각, 조퇴, 외출, 결석 1개라도 있을 시 제외
    - 정상 출석 및 공가 사용만 인정
    - 각 단위기간 출석률 100% 달성 시, 마일리지 **50,000원**
    

### 진행 시기 : 6단위기간

- **이력서/자소서 작성**
    - 지원 희망 기업이 있을 시, 해당 기업 서류 작성하여 제출
    - 희망 기업 별도로 없을 시, 플레이데이터 기본 양식 작성
        
        [플레이데이터 기본 이력서 양식.doc](%ED%94%8C%EB%A0%88%EC%9D%B4%EB%8D%B0%EC%9D%B4%ED%84%B0_%EA%B8%B0%EB%B3%B8_%EC%9D%B4%EB%A0%A5%EC%84%9C_%EC%96%91%EC%8B%9D.doc)
        
    - 작성 후 제출 시, 마일리지 **50,000원**
    - 희망자 대상 담당 매니저 서류 첨삭 진행

### 💵 리워드 적립/사용 방식

- 리워드 적립/사용
    - LMS 사이트 : [https://play-lms.web.app/login](https://play-lms.web.app/login)
    - 계정 정보 :
        - ID : 일련번호 12자리(디스코드 공지 확인)
        - PW : 생년월일 8자리
- 리워드 사용 방법
    - 매달 마지막주 사용 신청
        - 기프티콘 사용은 품목 제한 예정
        - 단, 수료일이 포함된 달의 경우 사용 신청일은 수료일까지로 제한
    - 신청분 취합하여 다음달 초 일괄 지급
        - 단, 도서는 배송상황에 따라 지급일이 늦춰질 수 있음.
        - 도서 사용 금액은 원가 기준
