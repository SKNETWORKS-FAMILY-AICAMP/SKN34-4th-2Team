Supervisor 경유 정책 답변 비교 — 준비 상태 (2026-10-10)

단위 테스트 4개 1회 통과. 첫 답변 평가 실행은 추적 전송 문제로 중단했다.
추적 비활성화 수정 후 사용자 재승인으로 단위 테스트 4개를 1회 재실행해 통과했다.
두 번째 답변 평가 실행은 6문항/12답변을 완료했다. 아래 결과를 참고한다.
운영 코드와 배포 설정은 수정하지 않았다.
evaluate_policy_answers.py는 기본적으로 준비 파일만 저장한다.
--execute는 사용자가 횟수를 승인한 경우에만 사용한다.

평가 조건
6문항: 34/40기별 장려금-마일리지 기존 질문 1개와
수료 기준 및 환급 조건의 새 표현 질문 2개씩이다.
4개는 새 표현이지만 기존 주제를 재사용하므로 독립적인 미사용 평가셋은 아니다.
질문은 실제 기수 정보와 분리하며 코퍼스 범위는 평가 세션 기수로 지정한다.
기존 supervisor 및 middleware를 질문마다 한 번 실행하고 두 방식이 결과를 공유한다.
운영 _queries_for_namespace, _policy_notice_retrieve, _answer를 재사용한다.
namespace 수에 따른 k 확대도 유지하므로 이전 top4 검색 실험과 직접 동등하지 않다.
검색 어댑터만 로컬 벡터 / 로컬 BM25+RRF로 교체하고 양쪽 모두 참조 확장을 수행한다.
Pinecone ANN, 서버 전체 요청 흐름, DB 조회는 실행하지 않는다.
공지 자료는 빈 fixture, 개인 기록·확정 일정은 미제공 상태를 답변에 전달한다.
supervisor가 요청한 student_scopes는 기록하되 개인 도구는 호출하지 않는다.
따라서 이 결과는 운영 전체 E2E 검증이나 개인 계산 검증으로 해석할 수 없다.
예상하지 못한 route/프로젝트 검색이면 결정을 보존하고 중단한다.

실행 예산 제안
새 단위 테스트 4개 1회, 답변 비교 6문항 1회.
supervisor 최대 6회 + 임베딩 최대 1회(검색 질문 최대 24개 batch)
+ 답변 생성 최대 12회 = 외부 API 최대 19회. 자동 재시도 0회.
기존 문서 임베딩은 재사용하며 원본 캐시는 수정하지 않는다.
모델 gpt-6-luna, 응답 토큰 상한 1600, streaming=False, timeout=60.
토큰 상한/streaming/retry 설정은 운영과 다른 평가 예산 설정이다.
첫 실행에서 supervisor 호출 시도 3회, 임베딩 0회, 답변 생성 0회가 기록되었다.
환경에 활성화된 LangSmith 추적 전송이 403 오류를 내어 실행을 중단했다.
추적 전송 실패 메시지 3개를 확인했으나 정확한 네트워크 요청 수는 확인하지 못했다.
평가 run에 tracing_context(enabled=False)를 추가했다. 수정 후 재검증은 하지 않았다.
기록: output/policy-evaluation/run-20261010-6-answers-01/interruption-note.txt
실패 뒤 재실행은 다시 확인한다.

검토 자료

supervisor: 질의 재작성, tasks, namespaces, student_scopes.
results: 검색 문서, 근거 지표, 답변, 출처, 답변 토큰 수와 소요 시간.
blind-review: 검색 방식 이름 없이 답변·근거·조건/예외 검토란.
blind-review-key: 방식 연결표. 자동 LLM 채점은 실행하지 않는다.
호출 실패 시 이미 완료한 결과를 저장하고 중단한다. 자동 이어 실행 없음.

환급 증빙·초과 결제 예외를 빠뜨리지 않는지, 출처가 답변을 뒷받침하는지,
초안 규정을 승인된 사실로 단정하지 않는지 확인한다.
로컬 검색 시간과 답변 모델 시간을 분리한다. 운영 응답시간 개선으로 단정하지 않는다.
