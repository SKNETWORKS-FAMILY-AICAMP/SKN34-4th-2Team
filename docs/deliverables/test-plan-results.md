## 1. 테스트 개요

공부방·복습 연습장을 제외한 AI 기능 5개를 검증한다. 3차에 있던 기능은 원본 질문·이력서·테스트 파일을 그대로 사용한다. 4차에서 추가된 기수별 정책 RAG, OCR, 코드 튜터, 관리자 AI·아카이빙은 합성 자료와 신규 케이스로 확인한다.

단위 테스트, 실제 모델 호출, DB 통합, 화면 테스트를 구분한다. 질문 분류의 통과율을 최종 답변 정확도로 사용하거나 엔진 자체 판정을 사람 평가로 사용하지 않는다.

3차 기준은 main 스냅샷 `215dd15881c576576f5e09bd52af5c156eb981ad`이다. [원본 출처·blob 해시](../reports/test_report_resume_review.md#3차-테스트-원본)와 [3차 README](https://github.com/SKNETWORKS-FAMILY-AICAMP/SKN34-3rd-2Team/blob/main/README.md)를 참고한다.

## 2. 테스트 목적

기수·권한에 맞는 근거 조회, 조건을 유지하는 공고 검색·추천, 이력서 사실 보존, 단계별 힌트, 관리자 확인 후 실행과 운영 기록 아카이빙을 확인한다. 기존 계약과 현재 구현의 차이는 실패로 기록하고 원인을 분류한다.

## 3. 테스트 환경과 방법

| 구분 | 환경·방법 |
| --- | --- |
| 로컬 | Windows, Python 3.12.10, 프로젝트 가상환경 |
| 도구 | unittest, pytest 9.1.1, Django 테스트 러너, Vitest, FastAPI TestClient |
| 실제 모델 | gpt-6-luna, OpenAI text-embedding-3-small |
| 검색 | 실제 Pinecone, 학생 RAG는 임시 namespace |
| DB | PostgreSQL 16.15, 127.0.0.1:55440의 격리 DB |
| 공고 데이터 | 운영 DB의 읽기 전용 복사본, 공고 92,597건 |
| 학생·관리자 자료 | 합성 정책·공지 이미지·조회 결과·운영 기록 |
| 화면 | React 선택 기능 테스트, 브라우저 E2E 제외 |

공고 상태·캐시 변경은 격리 DB에만 반영한다. 학생 RAG 임시 namespace는 검증 후 삭제했다. 관리자 모델의 SQL 도구·로그는 합성 fixture로 대체하며 실제 발송은 하지 않는다. 운영 학생 자료와 계정은 변경하지 않는다.

임시 파일·로컬 DB 접근이 샌드박스에서 차단된 실행은 같은 범위를 접근 가능한 환경에서 재실행했다. 재실행의 동일 테스트는 중복 집계하지 않는다. 수집 실패와 제품 테스트 실패도 구분한다.

## 5. 실패·성능·비용

### 실패와 후속 검토

| 대상 | 확인 내용 | 후속 조치 |
| --- | --- | --- |
| 학생 챗봇 | 기존 scope보다 추가 조회 범위를 선택한 6개 | 기수 공용·과제 데이터의 추가 조회 필요성과 최소 범위를 확인한다. |
| 채용 회귀 | 집계 답변·이벤트 계약 6개, 시간대 문자열 1개 불일치 | 현재 기대 계약과 동일 시각 비교 기준을 정한다. |
| 3차 첨삭 | 모델 이름 1개, SQLite fixture 10개, Gateway fixture 5개 불일치 | 변경된 저장소·인터페이스와 이전 계약을 구분해 관리한다. |
| 관리자 입력 | 학생 문서의 “챗봇 알림을 보내줘” 차단 누락 | 입력 필터와 실행 권한 검증을 함께 보강한다. |

추천 검사기의 SQLite 직접 조회는 PostgreSQL 저장소 접근으로 수정했다. 저장된 120건을 재검사했으며 추가 모델 호출 없이 규칙 검사를 완료했다. 발견된 다른 실패를 숨기기 위한 제품 변경은 하지 않는다.

### 관측 성능

실제 공고 검색 62턴의 중앙값은 약 5.8초, 최대는 약 15.9초이다. 추천 10회는 중앙값 31.35초, 최소 27.80초, 최대 37.80초이다. 순차 실행과 로컬 복사본의 결과이며 동시 사용자 부하·운영 SLA·3차 대비 개선율을 판정하지 않는다.

### API 사용량

수집된 모델 사용량은 입력 2,242,188토큰, 출력 110,075토큰이다. 캐시 정보를 반영한 수집분 추정액은 약 **US$0.093**이다. 첨삭 입력의 캐시 세부값은 없어 일반 입력 요금으로 계산했다. [사용량 집계](#api-사용량)에 근거를 남긴다.

추천 10회 모델 사용량과 일부 임베딩 사용량이 누락돼 위 금액은 전체 결제액이 아니다. 검사기 중단 전에 추천 토큰 기록이 저장되지 않았으며 비용 확인만을 위해 모델을 재호출하지 않는다. 청구서·Pinecone 비용·환율·세금은 확인하지 않는다.

계산은 gpt-6-luna 입력 US$0.10, 출력 US$0.50, 캐시 읽기 US$0.01, 캐시 쓰기 US$0.125 / 100만 토큰의 [공식 요금](https://developers.openai.com/api/docs/pricing/)을 기준으로 한다.

## 6. 결론과 검증 범위

현재 첨삭 회귀, 신규 튜터·기수 RAG·OCR, 실제 공고 검색·추천, 관리자 확인 카드와 아카이빙의 실행 근거를 확보했다. 학생 조회 범위·채용 회귀·관리자 입력 필터 및 이전 첨삭 계약의 불일치가 남아 있어 전체 통과로 판정하지 않는다.

추천의 사람 평가용 120행 CSV와 첨삭 검토용 산출물을 준비했다. 사람 평가, 브라우저 로그인부터 저장까지의 전체 흐름, 실제 알림 발송, PDF 다운로드, 지원서 전체 작성의 실제 모델 검증, AWS·Expo 검증은 수행하지 않는다.

2026-10-13의 Python 32개·React 65개 기록은 당시 선별 결과이다. 이번 결과와 합산하거나 최신 전체 통과 근거로 사용하지 않는다. 프로젝트 가이드의 [테스트 계획 및 결과 양식](https://drive.google.com/file/d/1dAaS_ELJv5pmN3WUf6mjbaqf6xdEtL0k/view)에 맞춰 목적·환경·케이스·결과·잔여 범위를 정리한다.
