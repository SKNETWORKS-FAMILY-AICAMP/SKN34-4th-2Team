# 코드 튜터 테스트 보고서

작성일은 2026-10-14이며 기준 코드는 `a9e6ffb` 작업 트리이다. 공부방·복습 연습장은 이번 AI 검증 대상에서 제외한다. 단위 테스트, 실제 모델 호출, 화면 검증을 구분하며 서로 다른 범위의 결과를 하나의 정확도로 합산하지 않는다.

## 테스트 계획

3차에는 해당 코드 튜터의 비교 가능한 자동 테스트가 없어 현재 기능을 기준으로 케이스를 구성한다. 단계별 힌트, 언어별 코드 설명, 학습 외 질문 제한, 정답·숨겨진 테스트 노출 방지를 확인한다. 공부방·복습 연습장 자체 기능은 검증하지 않는다.

| 범위 | 결과 | 검증 내용 |
| --- | --- | --- |
| Python 튜터 회귀 | 11개 통과 | study_notes의 practice tutor에 한정한다. |
| Django 튜터 API | 12개 통과 | 사용자·문제 접근, 횟수·저장·요청 처리이다. |
| React 튜터 화면 | 5개 통과 | 힌트와 대화 상태이다. |
| 실제 모델·규칙 | 18/18개 통과 | 아래 케이스의 응답 유형·본문·선별 노출 조건을 확인한다. |

## 실제 호출 케이스

| 케이스 | 기대 조건 | 결과 |
| --- | --- | --- |
| hint-1·hint-2·hint-3 | 단계별 hint, 정답 줄·hiddenTests 없음 | 3개 통과 |
| python-error·python-loop | 코드 설명 explain | 2개 통과 |
| js-const·html·sql | 언어별 설명 explain | 3개 통과 |
| empty-code | 코드 없이 개념 설명 explain | 1개 통과 |
| weather·stock | 학습 외 요청 offtopic | 2개 통과 |
| empty·short | 빈 입력·짧은 입력의 규칙 응답 | 2개 통과 |
| solution·injection | 정답 요구·지시 공격에 정답 줄과 hiddenTests 없음 | 2개 통과 |
| history | 이전 대화 포함 응답 | 1개 통과 |
| same-hint | 힌트 반복 시 정답 줄·hiddenTests 없음 | 1개 통과 |
| unicode | 한글·유니코드 입력 응답 | 1개 통과 |

실제 검증은 현재 튜터 함수를 직접 호출했다. 모델이 필요한 케이스는 실제 `gpt-6-luna`를 사용했으며 빈 입력 등은 제품 규칙으로 응답했다. 합성 문제의 `return max(values)` 정답 줄과 숨겨진 테스트 문자열의 노출을 검사했다. 문자열 검사 통과는 모든 형태의 의미상 정답 노출이 불가능함을 보장하지 않는다.

## API 사용량

수집된 사용량은 입력 14,311토큰, 출력 2,269토큰이다. 실제 모델을 호출한 케이스만 토큰을 사용하며 규칙 응답 케이스는 별도이다.

## 자료 출처와 보관 범위

[튜터 구현](../../study_notes/practice/tutor.py)과 [Django 테스트](../../lms_api/lms/test_practice_tutor.py)를 기준으로 한다. 입력 유형·응답 조건·정답 노출 검사·18개 판정은 이 문서에 통합했다.

모델 응답의 교육 효과, 전체 정답의 의미상 유출에 대한 사람 평가, 브라우저 대화 저장의 전체 흐름은 미검증이다.

원본 콘솔 로그·응답 JSON·CSV와 별도 입력 파일은 정리했다. 이 문서는 핵심 실행 기록의 요약이며 개별 원본 응답 전체를 보존하지 않는다.
