출결 안내 보완 검증 (2026-10-10)

서버가 목표까지 필요한 인정 출석일과 추가 정상 출석 필요일을 계산한다.
예외 출결 1회 추가 시 결석 환산이 늘어나는지를 별도 전달한다.
과거 미기록, 당일 미확인, 미래 미기록, 미래 선등록을 구분한다.
과거/당일 미확인 또는 미래 선등록이 있으면 추가 정상 출석 필요일을 null로 두고
기록 확인이 필요하다고 안내한다. 규칙·일정은 여전히 미검증 계산 가정이다.

사용자 승인 범위: 새 테스트 4개 + 기존 계산 테스트 7개, 총 11개 1회.
결과: 11개 모두 통과. 외부 모델 호출 0회, 운영 데이터 변경 0회.
사용자 실제 계정이 아닌 합성 날짜·출결 기록을 사용했다.

확인한 사례
- 18일 예정/14일 기록/지각 5회 → 인정 13일, 목표 15일, 추가 정상 출석 2일.
- 정상 출석 1일 추가 → 추가 정상 출석 필요일 1일.
- 새 수업일에 지각 1회 추가 → 기록일과 결석 환산 모두 증가, 인정 13일 유지.
- 과거 기록 누락/당일 미확인/미래 선등록 → 필요 출석일 확정 안내 보류.
- 기존 계산값 검증 및 소수 경계·잘못된 기준 거부 등 기존 7개 테스트 통과.

답변 프롬프트에 서버 수치 사용 및 조건 포함 지침을 추가했다.
이번 검증은 계산 단위 테스트이며 LLM의 문장 반영 여부는 재호출하지 않았다.
추출 문서별 정책 자동 적용, 승인 상태 변경, 운영 배포는 하지 않았다.
