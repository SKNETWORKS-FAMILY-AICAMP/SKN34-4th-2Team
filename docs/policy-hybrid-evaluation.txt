정책 하이브리드 검색 후보 — 설계 및 1차 평가 (2026-10-09)

목적
조 단위 청킹을 유지하고, 벡터 검색이 놓치는 규정 용어·수치 검색을
BM25와 순위 결합(RRF)으로 보완할 수 있는지 확인한다.
현재 코드는 평가 전용이다. 운영 retriever와 supervisor 연결은 변경하지 않았다.

입력과 범위
이전에 승인받아 실행한 20문항 임베딩 평가의 B(조 단위) corpus와 캐시를 읽는다.
동일 질문 원문으로 벡터 단독 top4와 하이브리드 top4를 비교한다.
각 검색 후보는 최대 12개, RRF 상수는 60이다. 자동 파라미터 탐색은 하지 않는다.
기수와 문서 버전을 먼저 제한한다. 다른 기수·버전이 섞이면 중단한다.
캐시가 없거나 유효하지 않으면 중단하며 API 호출로 대체하지 않는다.
원본 파일, DB, S3, Pinecone 데이터를 변경하지 않는다.

키워드 검색
NFKC 정규화와 소문자 변환, 한글 단어 내부 bigram을 사용한다.
80%와 100% 등 수치 토큰은 구별한다. 형태소 분석기는 사용하지 않는다.
쉼표 숫자/한글 숫자/퍼센트 표현 간 동의어 정규화는 아직 없다.
BM25 k1=1.2, b=0.75. 토큰이 전혀 겹치지 않는 문서는 후보에서 제외한다.
순위만 RRF로 합쳐 벡터 점수와 BM25 점수의 단위 차이를 피한다.
기수별 임계값이나 특정 평가 질문을 코드에 넣지 않는다.

평가와 판단
필요 조문 recall, 인용 근거 recall, 모든 근거 확보율, 기수 혼입,
질문별 개선·퇴행, 컨텍스트 길이를 비교한다.
로컬 연산 시간은 운영 서버나 Pinecone 응답시간을 의미하지 않는다.
supervisor, 참조 확장, 답변 생성은 양쪽 모두 제외한다.
따라서 이 결과만으로 실제 챗봇 답변 성능 개선·저하를 판정하지 않는다.
이 20문항은 이미 본 개발용 문항이므로 최종 품질 승인용 평가가 아니다.

실행 상태와 다음 단계
사용자 승인 후 단위 테스트 10개를 1회 실행하여 모두 통과했다.
20문항 × 2방식 = 40개 검색 결과를 만드는 비교 평가도 1회 완료했다.
외부 API 호출 0회, 재실행 0회. 추가 실행은 별도 확인한다.
근거 검색 평가 대상 16문항의 모든 근거 확보율: 벡터 14/16 → 하이브리드 16/16.
조문 평균 recall: 0.9375 → 1.0. 인용 근거 평균 recall: 0.958333 → 1.0.
개선된 질문: 34-mileage_attendance, 40-mileage_attendance.
두 질문 모두 제25조 마일리지와 함께 제16조 장려금이 top4에 포함되었다.
평가한 근거 검색 지표에서 퇴행 0건, 타 기수 혼입 0건.
전체 20문항 평균 컨텍스트 글자 수: 1387.95 → 1308.3.
근거 없음/개인 기록 질문 4개는 정답 근거 검색 지표에서 제외했다.
이 4개의 적절한 응답 거절·개인 기록 라우팅 동작을 검증한 것은 아니다.
결과 위치: 작업 문서 폴더 output/policy-evaluation/run-20261009-20-hybrid-01/
summary.json, results.json, manifest.json에 상세 결과와 입력·코드 해시를 저장했다.
이 결과는 검색 후보의 유효성을 보여주지만 운영 연동이나 배포 승인을 뜻하지 않는다.
운영 연동은 활성 기수 정책 버전에 맞는 키워드 색인 수명주기,
업로드/교체/삭제 시 일관성, 벡터 검색 fallback을 별도 설계해야 한다.
그다음 실제 supervisor 경유 평가와 미사용 질문 평가 횟수를 승인받는다.
rerank 및 Jev 실험은 후속 단계로 둔다.
